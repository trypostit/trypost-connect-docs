---
title: "Presign media upload"
api: "POST /media/presign"
description: "Get a signed URL to upload a file directly to storage, then attach it to a post."
---

Direct-to-storage upload for large files. PUT the bytes to `upload_url` with the returned headers, then attach via [`POST /posts/{post}/media/from-url`](/connect/endpoint/attach-media-from-url) using `public_url`.

`PUT /media/{token}` is the local/signed fallback for that presign — you do not call it with a Bearer token.

## Request

<ParamField body="filename" type="string" required>
  Original filename, including extension (e.g. `clip.mp4`).
</ParamField>

<ParamField body="content_type" type="string" required>
  MIME type. Allowed: `image/jpeg`, `image/jpg`, `image/png`, `image/gif`, `image/webp`, `video/mp4`, `video/quicktime`, `application/pdf`.
</ParamField>

<ParamField body="size" type="integer">
  Optional size in bytes. Used for validation against the per-type caps (10 MB image, 1 GB video, 100 MB document).
</ParamField>

## Response

<ResponseField name="upload_url" type="string">
  Signed URL to PUT the file bytes to.
</ResponseField>
<ResponseField name="public_url" type="string">
  Public URL to pass to [`from-url`](/connect/endpoint/attach-media-from-url) after the upload succeeds.
</ResponseField>
<ResponseField name="key" type="string">
  Storage key for the object.
</ResponseField>
<ResponseField name="expires_in" type="integer">
  Seconds until `upload_url` expires.
</ResponseField>
<ResponseField name="headers" type="object">
  Headers that must be sent with the PUT. Always includes `Content-Type`.
</ResponseField>

<RequestExample>
```bash
curl -X POST https://connect.trypost.it/api/media/presign \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "filename": "clip.mp4",
    "content_type": "video/mp4",
    "size": 10485760
  }'
```
</RequestExample>

<ResponseExample>
```json
{
  "upload_url": "https://...",
  "public_url": "https://...",
  "key": "temp/d4e5f6a7-b8c9-0d1e-2f3a-4b5c6d7e8f9a/01HX1A2B3C4D5E6F7G8H9I0J1K_clip.mp4",
  "expires_in": 3600,
  "headers": { "Content-Type": "video/mp4" }
}
```
</ResponseExample>
