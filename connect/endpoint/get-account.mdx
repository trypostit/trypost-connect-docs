---
title: "Get account"
api: "GET /account"
description: "Get the account bound to the API key. GET /workspace is the same payload (compat alias)."
---

## Response

Returns the account bound to the API key. [`GET /workspace`](/connect/endpoint/get-account) returns the same object.

<ResponseField name="id" type="string">
  The account UUID.
</ResponseField>
<ResponseField name="name" type="string">
  The account name.
</ResponseField>
<ResponseField name="created_at" type="string">
  Creation timestamp in `Y-m-d H:i:s` format.
</ResponseField>
<ResponseField name="updated_at" type="string">
  Last update timestamp in `Y-m-d H:i:s` format.
</ResponseField>

<RequestExample>
```bash
curl -X GET https://connect.trypost.it/api/account \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</RequestExample>

<ResponseExample>
```json
{
  "id": "d4e5f6a7-b8c9-0d1e-2f3a-4b5c6d7e8f9a",
  "name": "Acme",
  "created_at": "2026-09-01 00:00:00",
  "updated_at": "2026-09-01 00:00:00"
}
```
</ResponseExample>
