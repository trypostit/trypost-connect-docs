---
title: "Connect social account"
api: "GET /connect/{platform}"
description: "Start connecting a social account from your app. Returns a URL to open in the browser. After the user finishes, Connect redirects to your redirect_url."
---

Requires **manage accounts**. Connecting X, or a third non-X account, without a subscription returns **402**.

This is the same shape as a hosted social API: you send the user to `url`, **Connect hosts every picker and credential screen**, then the browser comes back to `redirect_url`. You do not send users to the Connect dashboard.

| `{platform}` | What `url` opens |
|---|---|
| `x` | X OAuth (always billable) |
| `tiktok` | TikTok OAuth |
| `youtube` | Google OAuth |
| `facebook` | Facebook OAuth, then Connect's Page picker when the login has more than one Page |
| `instagram` | Instagram Login (no Facebook Page) |
| `instagram-facebook` | Facebook OAuth, then Connect's Page picker for a Page-linked Instagram |
| `linkedin` | LinkedIn OAuth, then Connect's profile / Page picker |
| `linkedin-page` | LinkedIn OAuth scoped to Pages, then the same picker |
| `threads` | Threads OAuth |
| `pinterest` | Pinterest OAuth |
| `discord` | Discord OAuth |
| `bluesky` | Connect-hosted app-password form |
| `mastodon` | Connect-hosted instance URL form, then the instance's OAuth |
| `telegram` | Connect-hosted `/connect <code>` screen |

On success the browser is sent to `redirect_url` with `connected={platform}` and `id={social_account_id}`. Existing query params on `redirect_url` are kept. On failure the same URL receives `error` (for example `access_denied`, `invalid_state`, `session_expired`, `error_connecting`, `payment_required`).

A disabled platform returns **422** on `platform`.

## Request

<ParamField path="platform" type="string" required>
  One of: `x`, `tiktok`, `youtube`, `facebook`, `instagram`, `instagram-facebook`, `linkedin`, `linkedin-page`, `threads`, `pinterest`, `discord`, `bluesky`, `mastodon`, `telegram`.
</ParamField>

<ParamField query="redirect_url" type="string" required>
  Absolute URL Connect sends the user back to (`http` / `https`, or a custom scheme such as `myapp://callback`). Max 2048. Relative paths are rejected.
</ParamField>

## Response

<ResponseField name="url" type="string">
  Open this in the browser. OAuth platforms are the provider's authorize URL. Bluesky, Mastodon, and Telegram are a Connect-hosted page (`/connect/continue/{platform}?state=…`). Do not send a Personal Access Token to that URL.
</ResponseField>

<ResponseField name="state" type="string">
  Opaque token Connect binds to the account, user, platform, and `redirect_url`. Valid for 15 minutes.
</ResponseField>

<RequestExample>
```bash
curl "https://connect.trypost.it/api/connect/facebook?redirect_url=https://yourapp.com/oauth/done" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</RequestExample>

<ResponseExample>
```json
{
  "url": "https://www.facebook.com/v25.0/dialog/oauth?...",
  "state": "opaque-state-token"
}
```
</ResponseExample>
