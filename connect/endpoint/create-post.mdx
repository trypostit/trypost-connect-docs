---
title: "Create post"
api: "POST /posts"
description: "Create a new draft post targeting one or more social accounts. Returns the created post with status 201."
---

Creates a `draft`. To schedule or publish, follow up with [`PUT /posts/{post}`](/connect/endpoint/update-post) using `status=scheduled` or `status=publishing`.

<Note>
  Per-platform settings go in `platforms[].meta` and are accepted here on create. A few are **required to publish** — Pinterest `board_id`, TikTok `privacy_level` (string enum values like `"PUBLIC_TO_EVERYONE"`), Discord `channel_id` — but they're only enforced when you move the post to `scheduled`/`publishing`, not on this draft create. Full key list, limits, and examples: [`PUT /posts/{post}` → Per-platform meta](/connect/endpoint/update-post#per-platform-meta).

  Caption and media are shared by default (`content` + `media`). To send a different caption or media set to one network, put `custom_content` / `custom_media` on that `platforms[]` entry — they are siblings of `meta`, not inside it. `null` (or omitting the key) inherits the root; an empty string / empty array is an explicit override (no caption / no media).
</Note>

## Request

<ParamField body="platforms" type="array" required>
  At least one platform entry (`min:1`). Each entry pins this post to a connected social account and a `content_type`.
  <Expandable>
    <ParamField body="social_account_id" type="string" required>
      UUID of an active social account in the current account. Inactive or external accounts are rejected.
    </ParamField>
    <ParamField body="content_type" type="string" required>
      Format for this platform — must match the social account's platform. Discover the live catalog with [`GET /content-types`](/connect/endpoint/list-content-types).

      Allowed values today: `linkedin_post`, `linkedin_page_post`, `x_post`, `facebook_post`, `facebook_reel`, `facebook_story`, `instagram_feed`, `instagram_reel`, `instagram_story`, `tiktok_video`, `tiktok_photo`, `youtube_short`, `threads_post`, `pinterest_pin`, `pinterest_video_pin`, `pinterest_carousel`, `bluesky_post`, `mastodon_post`, `telegram_post`, `discord_message`.

      There is **no** `linkedin_carousel` / `instagram_carousel` — use `linkedin_post` + PDF for LinkedIn documents, and `instagram_feed` with multiple images for Instagram carousels.
    </ParamField>
    <ParamField body="custom_content" type="string">
      Caption for this platform only. Omit or send `null` to inherit the root `content`. An empty string publishes this platform with no caption. Max **10 000** characters at the API level; per-platform hard caps are measured against this value (not the root) when `scheduled_at` is set.
    </ParamField>
    <ParamField body="custom_media" type="array">
      Media for this platform only. Same item shape as root `media`. Omit or send `null` to inherit the root `media`. An empty array publishes this platform without media. Allowed file types are checked against **this** platform only, not the intersection of every selected platform.
    </ParamField>
    <ParamField body="meta" type="object">
      Optional per-platform settings. Only documented keys are stored; unknown keys are dropped.

      Summary (see [`PUT /posts/{post}`](/connect/endpoint/update-post#per-platform-meta) for the full contract):

      - **Instagram / Facebook** — `aspect_ratio` (`"1:1"` \| `"4:5"` \| `"16:9"` \| `"original"`)
      - **LinkedIn / LinkedIn Page** — `document_title` (max 300; PDF document posts)
      - **TikTok** — `privacy_level` (**required to publish**; exact strings `"PUBLIC_TO_EVERYONE"`, `"MUTUAL_FOLLOW_FRIENDS"`, `"FOLLOWER_OF_CREATOR"`, `"SELF_ONLY"`) plus booleans `allow_comments`, `allow_duet`, `allow_stitch`, `auto_add_music`, `is_aigc`, `disclose`, `brand_content_toggle`, `brand_organic_toggle`
      - **Pinterest** — `board_id` (**required to publish** — [`GET /social-accounts/{account}/boards`](/connect/endpoint/list-pinterest-boards)), `title` (max 100), `link` (http/https URL, max 2048). Pin description = this platform's effective caption (`custom_content` or post `content`).
      - **Discord** — `channel_id` (**required to publish** — [`GET /social-accounts/{account}/channels`](/connect/endpoint/list-discord-channels)), `channel_name`, `mentions` (`[{token, label}]`), `embeds` (up to 10)
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="content" type="string">
  The post body shared across all platforms. Up to **10 000** characters at the API level (per-platform hard caps are enforced separately — see [`GET /content-types`](/connect/endpoint/list-content-types)). Defaults to empty. For Pinterest, this is the pin description.
</ParamField>

<ParamField body="media" type="array">
  Optional media to attach on create. Each item must include a public `url` — the API downloads and hosts it.

  <Expandable>
    <ParamField body="url" type="string" required>
      Public `http`/`https` URL of the file (max 2048).
    </ParamField>
    <ParamField body="meta" type="object">
      Optional. `meta.alt_text` (string, max **2000**) for image accessibility. Not the same as `platforms[].meta`.
    </ParamField>
    <ParamField body="id" type="string">
      Optional — usually omitted on create (assigned after host).
    </ParamField>
    <ParamField body="path" type="string">
      Optional — usually omitted on create.
    </ParamField>
    <ParamField body="type" type="string">
      Optional hint: `image`, `video`, or `document`.
    </ParamField>
    <ParamField body="mime_type" type="string">
      Optional MIME hint.
    </ParamField>
    <ParamField body="original_filename" type="string">
      Optional display filename (max 500).
    </ParamField>
    <ParamField body="size" type="integer">
      Optional size in bytes.
    </ParamField>
    <ParamField body="source" type="string">
      Optional source tag (e.g. `ai`).
    </ParamField>
    <ParamField body="source_meta" type="object">
      Optional opaque source metadata.
    </ParamField>
  </Expandable>

  Prefer dedicated endpoints when practical: [`POST /posts/{post}/media`](/connect/endpoint/upload-media) (file), [`POST /posts/{post}/media/from-url`](/connect/endpoint/attach-media-from-url), or [`POST /posts/{post}/media/from-asset`](/connect/endpoint/attach-existing-asset) to reuse a library item.
</ParamField>

<ParamField body="scheduled_at" type="string">
  ISO 8601 datetime in the future (e.g. `2026-05-10T15:30:00Z`). Stored on the draft so a follow-up `PUT` with `status=scheduled` doesn't have to repeat it. **If omitted, the draft has `scheduled_at: null`** (no default time).
</ParamField>


## Response

Returns `201` with the created post (including `platforms[].meta`). Response shape matches [`GET /posts/{post}`](/connect/endpoint/get-post).

<RequestExample>
```bash
curl -X POST https://connect.trypost.it/api/posts \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "New pin from the Connect API",
    "platforms": [
      {
        "social_account_id": "b2c3d4e5-f6a7-8b9c-0d1e-2f3a4b5c6d7e",
        "content_type": "pinterest_pin",
        "custom_content": "Pin description for Pinterest only",
        "meta": {
          "board_id": "1234567890123456789",
          "title": "Summer lookbook",
          "link": "https://example.com/shop/summer"
        }
      }
    ],
    "scheduled_at": "2026-05-10T15:30:00Z"
  }'
```
</RequestExample>
