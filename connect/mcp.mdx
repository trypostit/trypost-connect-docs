[MCP](https://modelcontextprotocol.io) is how agents use Connect without a Personal Access Token. Same product as the [REST API](/connect) — posts, media, social accounts, webhooks — called as tools.

<Note>
  This is **Connect**. The [Build with AI](/ai/introduction) guides target the TryPost scheduler at `https://app.trypost.it/mcp/trypost` (workspaces, signatures, labels, repurposes). Do not mix the two URLs.
</Note>

## Server URL

```
https://connect.trypost.it/mcp
```

## Authentication

OAuth 2.1 with Dynamic Client Registration, PKCE, and the `mcp:use` scope. Supported clients discover this from `.well-known` — add the URL, click Connect, sign in at [connect.trypost.it](https://connect.trypost.it).

<Warning>
  API keys authenticate [`https://connect.trypost.it/api`](/connect#authentication) only. A Bearer token on `/mcp` returns **403**. For scripts and CI, use REST.
</Warning>

Revoke assistants under [Settings → MCP](https://connect.trypost.it/settings/workspace/mcp).

## Add a client

<AccordionGroup>
  <Accordion title="Cursor">
    Cursor 1.0+. In the project root, `.cursor/mcp.json`:

    ```json
    {
      "mcpServers": {
        "trypost-connect": {
          "url": "https://connect.trypost.it/mcp"
        }
      }
    }
    ```

    Open MCP settings → **Connect** next to **trypost-connect** → approve in the browser. Then: `List my Connect social accounts`.
  </Accordion>

  <Accordion title="Claude Code">
    ```bash
    claude mcp add --transport http trypost-connect https://connect.trypost.it/mcp
    ```

    Append `--scope user` to share it across projects. First tool call opens the Connect sign-in.
  </Accordion>

  <Accordion title="Claude web">
    [Customize → Connectors](https://claude.ai/customize/connectors) → **Add custom connector**. Name `TryPost Connect`, URL `https://connect.trypost.it/mcp`. Leave Client ID / Secret empty. Enable the connector on the chat **+** menu before asking it to post.
  </Accordion>

  <Accordion title="ChatGPT">
    Requires Pro/Plus/Business (or similar) and **Developer mode** on the web. [Create a connector](https://chatgpt.com/plugins#settings/Connectors?create-connector=true&redirectAfter=%2Fplugins): name `TryPost Connect`, URL `https://connect.trypost.it/mcp`, authentication **OAuth**, no client id/secret. In a new chat, turn on Developer mode and the connector.
  </Accordion>
</AccordionGroup>

## Recommended workflow

1. **`list-social-accounts-tool`** — connected accounts
2. **`list-content-types-tool`** — valid `content_type` and limits
3. **`list-pinterest-boards-tool`** / **`list-discord-channels-tool`** when those networks are in the post
4. **`create-post-tool`** — draft with `content`, optional `media[]`, and `platforms[]` (`custom_content` / `custom_media` / `meta` per network)
5. Attach more files if needed: `attach-media-from-url-tool`, `request-media-upload-tool` + `attach-media-from-upload-tool`, or `list-assets-tool` + `attach-existing-asset-tool`
6. **`preview-post-tool`** (optional)
7. **`publish-post-tool`** now, or **`update-post-tool`** with `status=scheduled`
8. **`get-post-metrics-tool`** after publish

Connecting a new Instagram / LinkedIn / … is still [`GET /connect/{platform}`](/connect/endpoint/connect-social-account) in a browser. There is no MCP connect tool.

## Posts

| Tool | Description |
|------|-------------|
| **list-posts-tool** | List posts on this account, newest schedule first. Filters: `status`, `search`, `limit` (1–100, default 50). |
| **get-post-tool** | One post by `post_id`, including `platforms[].custom_content`, `custom_media`, and `meta`. |
| **create-post-tool** | Draft. `content` (max 10 000), optional `scheduled_at` (stored; status stays `draft`), optional `media[]` (public HTTPS URLs — Connect hosts them), `platforms[]` with `social_account_id`, `content_type`, optional `custom_content`, `custom_media`, `meta`. Omit `custom_*` to inherit the shared caption/media. |
| **update-post-tool** | Draft only. `post_id`, optional `content`, `scheduled_at`, `status` (`draft` \| `scheduled`), `platforms[]` keyed by post-platform **`id`**. Send `custom_content` / `custom_media` as `null` to inherit again. Platforms not listed are disabled. Immediate publish is `publish-post-tool`. |
| **publish-post-tool** | Publish a draft. `post_id` plus optional future `scheduled_at`. Omit the date to publish now. Validates stored required meta and effective media. `IsDestructive`. |
| **preview-post-tool** | Per-platform sanitized caption (uses each row's effective `custom_content`). |
| **attach-media-from-url-tool** | Download public URLs onto a post. `post_id` + `urls` (`[{url, alt?}]`, max 10). |
| **request-media-upload-tool** | One-shot signed POST URL for a local file. Then `attach-media-from-upload-tool`. See [`POST /uploads/{token}`](/connect/endpoint/request-media-upload). |
| **attach-media-from-upload-tool** | Attach that upload. `post_id` + `upload_token`, optional `alt`. |
| **delete-post-tool** | Permanently delete. `IsDestructive`. |
| **get-post-metrics-tool** | Engagement for a published post. |

`platforms[].meta` is the same contract as REST — [Per-platform meta](/connect/endpoint/update-post#per-platform-meta).

## Assets

| Tool | Description |
|------|-------------|
| **list-assets-tool** | Asset Library. Optional `search`, `type` (`image` \| `video` \| `document`), `limit` 1–100 (default 50). Returns `{ assets, has_more }`. |
| **get-asset-tool** | One library file by `asset_id`. |
| **attach-existing-asset-tool** | Attach a library item to a draft/scheduled post. `post_id` + `asset_id`, optional `alt`. |

## Platforms

| Tool | Description |
|------|-------------|
| **list-content-types-tool** | Same catalog as [`GET /content-types`](/connect/endpoint/list-content-types). |

## Social accounts

| Tool | Description |
|------|-------------|
| **list-social-accounts-tool** | Connected accounts (`id`, `platform`, `display_name`, `username`, `is_active`, `status`). |
| **list-pinterest-boards-tool** | Boards for `account_id`. Use an `id` as `platforms[].meta.board_id`. Needs create-post permission. |
| **list-discord-channels-tool** | Channels for `account_id`. Use an `id` as `platforms[].meta.channel_id`. Same permission. |
| **toggle-social-account-tool** | Flip `is_active`. Needs manage-accounts (Owner / Admin). |

## Account

| Tool | Description |
|------|-------------|
| **get-workspace-tool** | Current account (`id`, `name`, timestamps). The tool name is leftover; Connect has no workspaces. |

## API keys

| Tool | Description |
|------|-------------|
| **list-api-keys-tool** | Personal Access Tokens (metadata only). Owner / Admin. |
| **create-api-key-tool** | Create a token. Response field is **`token`** (REST create uses `plain_token`). Owner / Admin. |
| **delete-api-key-tool** | Revoke. Cannot revoke the current OAuth session. `IsDestructive`. |

## Webhooks

Owner / Admin. Same events and HMAC as the [REST webhooks](/connect/endpoint/create-webhook).

| Tool | Description |
|------|-------------|
| **list-webhooks-tool** | List, secrets omitted. |
| **get-webhook-tool** | One webhook, includes `signing_secret`. |
| **create-webhook-tool** | `endpoint` + `events[]`. Returns the secret. |
| **update-webhook-tool** | `endpoint`, `events`, `status` (`enabled` \| `disabled`). |
| **send-webhook-test-tool** | Signed `webhook.test` ping. |
| **rotate-webhook-secret-tool** | New secret immediately. `IsDestructive`. |
| **list-webhook-logs-tool** | Delivery logs. `limit` 1–100, default 50. |
| **replay-webhook-log-tool** | Queue a new delivery from a log. |
| **delete-webhook-tool** | Delete webhook and logs. `IsDestructive`. |

## Troubleshooting

<AccordionGroup>
  <Accordion title="HTTP 402 — Active subscription required">
    The OAuth grant is fine; the account lost app access (billable social accounts without an active card). Open [connect.trypost.it](https://connect.trypost.it), subscribe, reconnect. Two non-X accounts stay free; X and extras need a card — see [Billing](/connect#billing).
  </Accordion>
  <Accordion title="HTTP 401 — Unauthenticated">
    Session expired or the token was revoked. Run the client's Connect flow again.
  </Accordion>
  <Accordion title="HTTP 403 — MCP OAuth authorization required">
    The request used an API key (or an OAuth token without `mcp:use`). Remove any `Authorization` header from the MCP config.
  </Accordion>
  <Accordion title="Tools look like the scheduler (signatures, labels, workspaces)">
    The client is pointed at `https://app.trypost.it/mcp/trypost`. Change the URL to `https://connect.trypost.it/mcp` and reconnect.
  </Accordion>
</AccordionGroup>
