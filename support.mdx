Do not share API keys, OAuth secrets, or payment details in public channels.

## How to ask

**Goal → Environment → Changes → Results.**

- What you were calling (`POST /posts`, MCP `publish-post-tool`, connect redirect…)
- HTTP status and the `message` body
- Whether this is REST, MCP, or the playground
- What changed (new network, new key, subscription lapsed)

Include the post id or social-account id when you have one. Never paste a live Bearer token.
