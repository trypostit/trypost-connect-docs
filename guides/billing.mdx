TryPost Connect is one plan: **$3 per billable social account / month**.

Manage the card and invoices under [Settings → Billing](https://connect.trypost.it/settings/account/billing). Checkout charges immediately — no generic trial, no promo-code field, no first-month coupon.

## What counts

| | Billable? |
|---|---|
| First two non-X accounts | No |
| Each extra non-X account | Yes — $3 / month |
| Twitter / X | Always — $3 / month each |

```
quantity = xCount + max(0, nonXCount - 2)
```

Two free non-X accounts still work when quantity is 0.

Connecting beyond that allowance — or connecting X — without a card is refused (dashboard sends you to billing; the API returns **402**). The same happens later if the subscription lapses and you still have paid quantity.

After connect or disconnect, Connect updates Stripe. Quantity 0 cancels at period end.

Fix billing in the dashboard, then retry. There is nothing to pass in the API to “unlock” a 402.
