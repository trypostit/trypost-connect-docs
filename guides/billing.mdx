TryPost Connect sells one plan: **Connect**, $3 per billable social account / month.

Manage the card and invoices under [Settings → Billing](https://connect.trypost.it/settings/account/billing). Stripe Checkout charges immediately — no generic trial, no promotion-code field, no first-month coupon.

## What counts

| | Counts as billable? |
|---|---|
| First two non-X accounts | No |
| Each extra non-X account | Yes — $3 / month |
| Twitter / X | Always — $3 / month each |

```
quantity = xCount + max(0, nonXCount - 2)
```

Connecting beyond the free allowance, or connecting X, without an active subscription returns **402** on the API (and the dashboard sends you to billing).

The same **402** applies to the rest of the API when the account no longer has app access (paid quantity, subscription inactive).

Two free non-X accounts still have access when quantity is 0.

After connect or disconnect, Connect syncs Stripe quantity. Quantity 0 cancels the subscription at period end.

## API

A **402** body is `{ "message": "…" }`. Fix it in the dashboard, then retry.
