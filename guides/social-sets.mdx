A social set is a name and a color on **your** Connect account. You put connected identities in it so a brand, a client, or a campaign stays together.

It is not a workspace and not a second tenant. Everyone on the account still sees every set. Sets are optional — identities with no set are just ungrouped.

You can create, rename, recolor, and delete sets from the [dashboard](https://connect.trypost.it/accounts) or the [API](/api-reference/social-sets/list). Deleting a set does not disconnect anyone; those identities become ungrouped.

The name is unique on your account. The color is a six-digit hex value (`#2563EB`).

## What you use them for

- Filter the account list when you only care about one brand.
- Keep two clients’ Instagrams from looking like one pile.
- Assign or ungroup an identity without reconnecting it.

Agents can create sets and move accounts. They cannot filter the account list by set — do that in REST or the dashboard.
