A social set is a named, colored group of social accounts on **your** Connect account. It is not a workspace and not a second tenant.

Sets are optional. Accounts with `set_id: null` are ungrouped.

## CRUD

| Method | Path |
|---|---|
| `GET` | [`/social-sets`](/api-reference/social-sets/list) — plain array |
| `POST` | [`/social-sets`](/api-reference/social-sets/create) — `name`, `color` (exactly `#` + 6 hex digits, e.g. `#2563EB`) |
| `GET` | [`/social-sets/{id}`](/api-reference/social-sets/get) |
| `PUT` | [`/social-sets/{id}`](/api-reference/social-sets/update) |
| `DELETE` | [`/social-sets/{id}`](/api-reference/social-sets/delete) — `204`. Accounts in the set become ungrouped. |

`name` is unique per Connect account.

## Assign an account

```bash
curl -X PUT https://connect.trypost.it/api/social-accounts/$ID/set \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"set_id":"00000000-0000-0000-0000-000000000000"}'
```

Send `"set_id": null` to ungroup.

Filter the account list: [`GET /social-accounts?set_id={uuid}`](/api-reference/social-accounts/list) or `?set_id=unassigned` for ungrouped identities. MCP `list-social-accounts-tool` has no `set_id` filter.

MCP mirrors this: `list-social-sets-tool`, `create-social-set-tool`, `assign-social-set-tool`.
