Authenticate with a Bearer token. See [Authentication](/getting-started/authentication).

Try the same routes in the [playground](https://connect.trypost.it/playground).

## Quick reference

| Resource | Endpoints |
|---|---|
| Posts | [`GET /posts`](/api-reference/posts/list), [`POST /posts`](/api-reference/posts/create), [`GET /posts/{id}`](/api-reference/posts/get), [`PUT /posts/{id}`](/api-reference/posts/update), [`DELETE /posts/{id}`](/api-reference/posts/delete), [`GET /posts/{id}/metrics`](/api-reference/posts/metrics), [`GET /posts/{id}/preview`](/api-reference/posts/preview) |
| Media | [`POST /medias/presign`](/api-reference/media/presign), [`PUT /medias/{token}`](/api-reference/media/upload) (signed, no Bearer) |
| Social accounts | [`GET /social-accounts/connect/{platform}`](/api-reference/social-accounts/connect), [`GET /social-accounts`](/api-reference/social-accounts/list), [`DELETE /social-accounts/{id}`](/api-reference/social-accounts/disconnect), [`PUT /social-accounts/{id}/set`](/api-reference/social-accounts/assign-set), [`GET /social-accounts/{id}/boards`](/api-reference/social-accounts/boards), [`GET /social-accounts/{id}/channels`](/api-reference/social-accounts/channels) |
| Social sets | [`GET /social-sets`](/api-reference/social-sets/list), [`POST /social-sets`](/api-reference/social-sets/create), [`GET /social-sets/{id}`](/api-reference/social-sets/get), [`PUT /social-sets/{id}`](/api-reference/social-sets/update), [`DELETE /social-sets/{id}`](/api-reference/social-sets/delete) |
| Account | [`GET /account`](/api-reference/account/get) |
| API keys | [`GET /api-keys`](/api-reference/api-keys/list), [`POST /api-keys`](/api-reference/api-keys/create), [`DELETE /api-keys/{id}`](/api-reference/api-keys/delete) |
| Logs | [`GET /logs`](/api-reference/logs/list), [`GET /logs/{id}`](/api-reference/logs/get) |
| Webhooks | [`GET /webhooks`](/api-reference/webhooks/list), [`POST /webhooks`](/api-reference/webhooks/create), [`GET /webhooks/{id}`](/api-reference/webhooks/get), [`PUT /webhooks/{id}`](/api-reference/webhooks/update), [`DELETE /webhooks/{id}`](/api-reference/webhooks/delete), [`POST /webhooks/{id}/send-test`](/api-reference/webhooks/send-test), [`POST /webhooks/{id}/rotate-secret`](/api-reference/webhooks/rotate-secret), [`GET /webhooks/{id}/logs`](/api-reference/webhooks/logs), [`POST /webhooks/{id}/logs/{log_id}/replay`](/api-reference/webhooks/replay) |

There are no `/assets`, `/content-types`, `/signatures`, `/labels`, `/repurposes`, or `/workspace` routes.

## Pagination

These lists paginate (`data`, `links`, `meta`). Use `page`. Size is `meta.per_page` (default 25). There is no `per_page` query.

- [`GET /posts`](/api-reference/posts/list)
- [`GET /logs`](/api-reference/logs/list)
- [`GET /webhooks/{id}/logs`](/api-reference/webhooks/logs)

Everything else that lists resources returns a **plain array**.
