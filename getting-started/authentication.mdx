## REST API

Base URL:

```
https://connect.trypost.it/api
```

There is no `api.connect.trypost.it`. Every authenticated route needs:

```bash
Authorization: Bearer YOUR_API_KEY
```

Create keys in the dashboard at [API keys](https://connect.trypost.it/api-keys) or with [`POST /api-keys`](/api-reference/api-keys/create). The plain token is returned **once**.

<Warning>
  Keep the key on a server. Do not ship it in a browser app or a public repo.
</Warning>

API keys are bound to the account that created them. Connect has one account per customer — every request acts on that account.

The in-app [playground](https://connect.trypost.it/playground) uses the same Bearer contract.

## Rate limits

Authenticated API routes are **60 requests / minute** per account (`429` + `Retry-After`). Local development is unlimited.

[`GET /social-accounts/{id}/boards`](/api-reference/social-accounts/boards) and [`/channels`](/api-reference/social-accounts/channels) are **60 / minute** on their own.

The signed media PUT is **60 / minute per account** and **1200 / minute per IP**.

## MCP

Agents authenticate with **OAuth 2.1** (`mcp:use`) and Dynamic Client Registration. Add `https://connect.trypost.it/mcp`, click Connect, and sign in.

<Warning>
  A Personal Access Token on `/mcp` returns **403**. Scripts and CI should call REST.
</Warning>

Revoke assistants under [Settings → MCP](https://connect.trypost.it/settings/account/mcp). Setup: [MCP](/guides/mcp).

## Errors

All error bodies include a `message` field. Validation errors also include `errors`.

| Status | Meaning |
|--------|---------|
| `200` | Success |
| `201` | Created |
| `204` | Deleted |
| `401` | Missing or invalid API key |
| `402` | Card / active subscription required |
| `403` | Forbidden (role, or an API key sent to `/mcp`) |
| `404` | Missing, or not on this account |
| `422` | Validation |
| `429` | Rate limit — wait `Retry-After` seconds |

```json
{
  "message": "The name field is required."
}
```

A **402** on connect or any other call means the account needs a card (X, or a third non-X identity) or lost app access. See [Billing](/guides/billing).

## Response shape

Resources are **unwrapped** — no `data:` envelope on a single object.

Non-paginated lists (social accounts, social sets, API keys, webhooks) are a **plain JSON array**.

Paginated lists wrap in Laravel's `data` / `links` / `meta`:

- [`GET /posts`](/api-reference/posts/list)
- [`GET /logs`](/api-reference/logs/list)
- [`GET /webhooks/{id}/logs`](/api-reference/webhooks/logs)

Page size is `meta.per_page` (default **25**). There is no `per_page` query. Use `page`.
