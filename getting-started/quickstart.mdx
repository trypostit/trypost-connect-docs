This walkthrough uses the REST API. The same flow exists in the [playground](https://connect.trypost.it/playground) and, after accounts are connected, as [MCP tools](/guides/mcp).

<Steps>
  <Step title="Create an account">
    Sign up at [https://connect.trypost.it/register](https://connect.trypost.it/register). One account per customer — no workspaces.
  </Step>

  <Step title="Create an API key">
    In the dashboard go to **[API keys](https://connect.trypost.it/api-keys)** and create a key. The plain token is shown once.

    ```bash
    export TRYPOST_API_KEY='your_key'
    export TRYPOST_API='https://connect.trypost.it/api'
    ```

    Every authenticated request sends `Authorization: Bearer $TRYPOST_API_KEY`.
  </Step>

  <Step title="Connect a social account">
    The API never 302s your server. It returns a URL for the **end user's browser**. After OAuth (or a Connect-hosted picker), the browser lands on *your* `redirect_url`.

    ```bash
    curl "$TRYPOST_API/social-accounts/connect/x?redirect_url=https://yourapp.com/connected" \
      -H "Authorization: Bearer $TRYPOST_API_KEY"
    ```

    ```json
    {
      "url": "https://twitter.com/i/oauth2/authorize?…",
      "state": "opaque-state-token"
    }
    ```

    Open `url` in the browser. On success Connect redirects to:

    ```
    https://yourapp.com/connected?connected=x&id={social_account_id}
    ```

    On failure the same URL receives `error` (for example `access_denied`, `payment_required`). Then list accounts:

    ```bash
    curl "$TRYPOST_API/social-accounts" \
      -H "Authorization: Bearer $TRYPOST_API_KEY"
    ```

    Details: [Connect accounts](/guides/connect-accounts).
  </Step>

  <Step title="Upload media">
    External file URLs are not accepted. Presign, `PUT` the bytes (no Bearer token), then use `public_url` on the post.

    ```bash
    curl -X POST "$TRYPOST_API/medias/presign" \
      -H "Authorization: Bearer $TRYPOST_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"filename":"photo.jpg","content_type":"image/jpeg","size":102400}'
    ```

    ```bash
    curl -X PUT "$UPLOAD_URL" \
      -H "Content-Type: image/jpeg" \
      --data-binary @photo.jpg
    ```

    Details: [Media](/guides/media).
  </Step>

  <Step title="Create and publish a post">
    `POST /posts` always creates a **draft**. Publish with `PUT /posts/{id}` and `status=publishing`, or schedule with `status=scheduled`.

    ```bash
    curl -X POST "$TRYPOST_API/posts" \
      -H "Authorization: Bearer $TRYPOST_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "content": "Hello from Connect",
        "media": [{ "url": "https://…/temp/…/photo.jpg" }],
        "platforms": [
          {
            "social_account_id": "00000000-0000-0000-0000-000000000000",
            "content_type": "x_post"
          }
        ]
      }'
    ```

    ```bash
    curl -X PUT "$TRYPOST_API/posts/$POST_ID" \
      -H "Authorization: Bearer $TRYPOST_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"status":"publishing"}'
    ```

    One post can target many networks. Per-network caption and media go in `platforms[].custom_content` / `custom_media`. Details: [Posts](/guides/posts).
  </Step>
</Steps>
